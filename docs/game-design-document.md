# 残酷育儿模拟器 · 游戏策划文档

## 1. 概述与愿景

**游戏名称**：残酷育儿模拟器
**类型**：生活模拟 / 数值策略
**平台**：纯 Web 前端（HTML + CSS + JavaScript）
**目标用户**：对育儿话题感兴趣的玩家，尤其是年轻成年人
**运行方式**：直接打开 `index.html`，无需构建或服务器

**核心愿景**：在资源（金钱、睡眠、情绪）永远不够用的 365 天里，让玩家做出每一个看似普通却很要命的决定。通过高压力数值系统和阶段性事件，让玩家体验真实育儿中的焦虑感与不可逆选择的后果。

**关键词**：有限资源管理、阶段性危机、不可逆决策、真实育儿模拟

## 2. 游戏循环

```
┌──────────────────────────────────────────────────────┐
│                    游戏主循环                          │
│                                                      │
│  requestAnimationFrame                              │
│       ↓                                              │
│  tick(delta) ──→ decay() ──→ updateCooldowns()      │
│       ↓                                              │
│  maybeShowEvent() ──→ checkEnding()                  │
│       ↓                                              │
│  render() ──→ renderBaby() / renderActions()         │
│       ↓                                              │
│  requestAnimationFrame (next frame)                  │
└──────────────────────────────────────────────────────┘
```

**帧率驱动**：由 `requestAnimationFrame` 驱动，每帧计算 delta 时间。1 游戏秒 = 1 实际秒。

**时间流速**：1 实际秒 = 2 游戏分钟，支持 0.2x / 0.5x / 1x / 2x / 4x 五档变速，玩家可通过 `[` / `]` 键切换。

**昼夜系统**：游戏分钟 0-360（00:00-06:00）为夜间，360-1200（06:00-20:00）为白天，1200-1440（20:00-24:00）为夜间。夜间衰减倍率 ×1.35。

**每日结算**：每跨过 1440 分钟（午夜）执行 `chargeDaily()`，扣除当日奶粉费和尿布费。

## 3. 数值系统

### 3.1 婴儿属性（6 项）

| 属性 | 初始值 | 范围 | 衰减特性 | 关键阈值 |
|------|--------|------|----------|----------|
| 饱腹度 | 82 | 0-100 | 基础 -1.3/秒，夜间 ×1.35 | <25 哭泣，<35 表情异常 |
| 精力值 | 78 | 0-100 | 基础 -0.9/秒，夜间 ×1.35 | <18 哭泣，<28 疲倦表情 |
| 舒适度 | 80 | 0-100 | 基础 -0.7/秒，夜间 ×1.35 | <25 哭泣，<35 建议换尿布 |
| 安全感 | 80 | 0-100 + 上限 | 基础 -0.5/秒，夜间 ×1.35 | <22 哭泣，<35 建议陪玩 |
| 健康值 | 92-100 | 0-100 | 四属性均值 <22 时 -2.1/秒；哭泣 >18 秒 -2.5/秒 | ≤0 触发残酷结局 |
| 发育进度 | 0 | 0-100 | 每秒 +0.015 | 365 天时用于计算结局评分 |

**哭泣触发条件**（任一满足即哭泣）：
- 饱腹度 < 25
- 精力值 < 18
- 舒适度 < 25
- 安全感 < 22
- 健康值 < 32

**安全感上限**：基础 100，开局采购的大件档次可额外增加上限（+5 或 +12）。

### 3.2 父母属性（2 项）

| 属性 | 初始值 | 范围 | 恢复/消耗规则 |
|------|--------|------|--------------|
| 精力值 | 80-120 | 0 - 上限（由家庭模式决定） | 白天（06:00-20:00）每秒恢复 0.9 × 恢复倍率；执行操作消耗 |
| 情绪值 | 94 | 0-100 | 婴儿哭泣时每秒 -0.45；每次操作 -0.5；每日清晨 +8 |

**恢复倍率**由家庭模式决定：单职工 1.2，双职工 0.8。

### 3.3 资金

- **初始资金** = 家庭总收入 - 开局采购总花费
- **每日消耗** = 每日奶粉费 + 每日尿布费（由采购档次决定）
- **资金见底惩罚**：资金 ≤ 0 时，所有衰减倍率 ×2
- **超支限制**：初始资金不得低于 -20000，否则禁止开始游戏

### 3.4 衰减公式

```
每帧衰减 = 基础衰减 × 夜间倍率 × 资金惩罚倍率 × 时间缩放

其中：
- 夜间倍率 = state.minute < 360 || minute >= 1200 ? 1.35 : 1
- 资金惩罚倍率 = state.money <= 0 ? 2 : 1
- 时间缩放 = delta × state.speed
```

**阶段特殊状态叠加**：

| 阶段状态 | 受影响属性 | 额外衰减量 |
|----------|-----------|-----------|
| 黄疸 | 舒适度 | +0.25 |
| 睡眠倒退 | 精力值 | +0.55 |
| 出牙 | 舒适度 | +0.6 |
| 分离焦虑 | 安全感 | +0.65 |
| 挑食 | 饱腹度 | +0.4 |

## 4. 阶段系统

游戏按月龄划分为 5 个阶段，每阶段有特定状态和持续天数。

```
月龄 0 ──── 月龄 1 ──── 月龄 4 ──── 月龄 6 ──── 月龄 9 ──── 月龄 12
  │           │           │           │           │
  ▼           ▼           ▼           ▼           ▼
新生儿期   胀气睡眠期   出牙辅食期   分离焦虑期   学步探索期
(黄疸)     (睡眠倒退)   (出牙)      (分离焦虑)   (挑食)
 5天         4天         6天          8天         7天
```

**阶段切换逻辑**：
```javascript
// 当前月龄（从 0 开始）
currentMonth() = Math.min(11, Math.floor((state.day - 1) / 30.4))

// 当前阶段状态
activeStatus() = dayInStage <= stage.duration ? stage.status : ""
```

## 6. 突发事件系统

### 6.1 事件池结构

事件按月龄阶段分为 5 个池，昼夜切换时随机入队 1-3 个事件。

```
EVENT_POOLS
├── newborn  (月龄 0)
│   ├── 脐带红肿
│   ├── 吐奶呛奶
├── sleep    (月龄 1-3)
│   ├── 肠绞痛爆发
│   ├── 厌奶期
├── teething (月龄 4-5)
│   ├── 出牙发烧
│   ├── 辅食过敏
├── anxiety  (月龄 6-8)
│   ├── 跌落受伤
│   ├── 异物入口
└── toddler  (月龄 9-11)
    ├── 摔伤磕碰
    └── 挑食爆发
```

### 6.2 事件结构

每个事件包含：标题、描述、3 个选项。

**选项设计原则**：每个事件都有一个**正确答案**（0 花费或低花费，效果正面）、一个**付费选项**（花费金钱，效果更正面）、一个**错误选项**（0 花费，效果负面）。

**医疗折扣**：选项标记 `choiceMedical: true` 时，花费 × `medicalDiscount`（由医疗采购档次决定：基础 1.0 / 中档 0.7 / 高档 0）。

**事件队列**：事件依次弹出显示，玩家必须做出选择才能继续游戏。

```

```

## 9. 结局系统

### 9.1 残酷结局
**触发条件**：健康值 ≤ 0
**结局文案**：「健康值归零，照护系统彻底崩溃。这不是一次轻松失败，而是提醒：长期忽视会迅速吞掉所有余地。」

### 9.2 通关结局
**触发条件**：第 365 天结束

**评分公式**：
```
score = baby.development + Math.max(0, state.money / 1000)
```

| 评分区间 | 结局标题 |
|----------|----------|
| > 92 | 了不起的父母 |
| 65 - 92 | 温暖的家庭 |
| < 65 | 新手爸妈辛苦了 |

**结局文案**：「宝宝迎来 1 岁生日。发育进度 X，剩余资金 ¥XXX。」

## 11. 数据配置结构

所有游戏数据以 CSV 格式存储在 `config.js` 中，由内置 CSV 解析器在运行时解析。

**CSV 文件与游戏数据映射**：

| CSV 文件 | 解析后对象 | 用途 |
|----------|-----------|------|
| `families.csv` | `FAMILIES[]` | 家庭模式列表 |
| `purchases.csv` | `PURCHASES{}` | 开局采购配置（按 category 分组） |
| `stages.csv` | `STAGES[]` | 发育阶段定义 |
| `actions.csv` | `ACTIONS[]` | 日常操作定义 |
| `events.csv` | `EVENT_POOLS{}` | 突发事件池（按 pool 分组） |
