# 残酷育儿模拟器

一个基于 HTML/CSS/JavaScript 的可运行前端原型。直接打开 `index.html` 即可试玩。

## 已实现

- 单/双职工选择、家庭总收入输入与四类开局采购。
- 资金、父母精力、父母情绪、婴儿六项属性。
- 1 秒 = 2 游戏分钟，并支持 0.2x / 0.5x / 1x / 2x / 4x 变速。
- 9 个日常操作、冷却、消耗、阶段修正和 6 月辅食解锁。
- 按月龄切换阶段，并在昼夜切换时触发事件队列。
- 医疗折扣、每日奶粉和尿布消耗、资金见底惩罚。
- Canvas 婴儿表情、哭闹红光、日志和百科面板。
- 暗色育儿室背景、监护面板式 UI、状态徽章和更细的婴儿状态表现。
- 健康归零与 365 天通关结局。

## 操作

- 点击日常操作按钮照护宝宝。
- 点击宝宝下方的“轻拍安抚”可小幅恢复安全感。
- 使用 `[` 和 `]` 调整时间速度。

## 主要文件

- `index.html`：页面结构。
- `styles.css`：界面样式。
- `game.js`：游戏数据、循环、事件和 Canvas 绘制。
- `assets/nursery-bg.svg`：育儿室背景资源。
